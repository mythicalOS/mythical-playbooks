# Support

**Bugs and defects** — open an issue using the issue templates. Include the commit you are
on, what you did, what you expected, and what happened instead.

**Questions and ideas** — use the repository's
[Discussions](../../discussions). Please check the README and existing issues and
discussions first; the answer is often already there.

**Security issues** — never through issues or discussions. Follow
[SECURITY.md](SECURITY.md).

This project is maintained by a small team on a best-effort basis; there is no guaranteed
response time.
